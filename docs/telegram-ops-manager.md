# Работа менеджера с заявками в Telegram (ops-бот)

Краткий сценарий. Полная операционка и брони — в Twenty CRM
([manager guide](../../Project_KAT_context/studio/docs/katfit-balance-crm-manager-guide.ru.md)).

## Куда смотреть

Закрытая супергруппа студии. Каждая новая заявка с лендинга — сообщение с контактами и кнопками.

## Кнопки

| Кнопка | Что пишется в CRM |
| --- | --- |
| Пообщались | Стадия «Связались», Note («пообщались в мессенджере / по почте»), закрывается задача «Написать клиенту» |
| Нет ответа / Написать снова | Note («написала — ответа нет») + задача «Написать снова» (стадию не двигает) |
| Предложила intro | Стадия «Предложено intro» + задача на слот |
| Записала intro | Стадия «Intro записано» + Note (Booking в календаре — вручную в CRM) |
| Посетила intro | Стадия «Intro посещено» + задача «Предложить пакет» |
| No-show | Note + задача на повторный контакт |
| Купила пакет | Стадия «Первая покупка», клиент «Активный» |
| Потерян | Стадия «Потерян» + причина |

Контакт с клиентом — **мессенджер или почта**, не звонок.

## Ответ на сообщение (секретарь)

Ответьте **reply** на карточку заявки:

- «Написала, никто не ответил…» / «Нет ответа…» → как «Нет ответа»
- «Пообщались в мессенджере…» / «Ответила в Telegram…» → как «Пообщались» + текст в Note
- «Записала на intro …» → intro записано + текст слота в Note
- «Потерян: цена» → потерян с причиной
- любой другой текст → только Note

Не пишите в заметках диагнозы и лишние ПДн.
