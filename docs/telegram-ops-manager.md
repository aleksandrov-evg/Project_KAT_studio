# Работа менеджера с заявками в Telegram (ops-бот)

Краткий сценарий. Полная операционка и брони — в Twenty CRM
([manager guide](../../Project_KAT_context/studio/docs/katfit-balance-crm-manager-guide.ru.md)).

## Куда смотреть

Закрытая супергруппа студии. Каждая новая заявка с лендинга — сообщение с контактами и кнопками.

## Первое касание (два шага)

### 1. Канал

Сначала отметьте, **куда** написали / позвонили:

| Кнопка | Что в статусе карточки | CRM |
| --- | --- | --- |
| 📞 Звонок | Позвонила | Note «Попытка: Звонок» + `lastContactChannel=CALL` |
| SMS | Написала SMS | Note + `SMS` |
| MAX | Написала в MAX | Note + `MAX` |
| Telegram | Написала в Telegram | Note + `TELEGRAM` |
| WhatsApp | Написала в WhatsApp | Note + `WHATSAPP` |

Стадия сделки на этом шаге **не** меняется — ждём исход.

Ссылки **Открыть TG / Открыть WA** сверху только открывают чат.

### 2. Исход

| Кнопка | CRM | Дальше |
| --- | --- | --- |
| Нет ответа | `no_answer` + Note с каналом; стадию не двигает | снова выбор канала + «Написать снова» |
| Ответили | `contacted` + Note с каналом | кнопки intro / повтор |
| Думает | `contacted` + Note «думает» + Task «Вернуться к думающим» (+2 дня) | кнопки intro / повтор |
| ← Другой канал | без смены стадии | снова выбор канала |

## На стадии «Связались» (CONTACTED)

| Кнопка | CRM |
| --- | --- |
| Предложила intro | `intro_offered` + Note «Предложила intro» |
| Согласилась на intro | тот же `intro_offered` + Note «Согласилась на intro» |
| Записала intro | `intro_booked` |
| Написать снова | выбор канала → исход (в т.ч. «Нет ответа»), стадия CONTACTED |
| Потерян | причина потери |

В Twenty: представление **Связались — ждут intro** + Tasks «Вернуться к думающим» / «Написать снова».

## Дальше по воронке

| Кнопка | Что пишется в CRM |
| --- | --- |
| Посетила intro | Стадия «Intro посещено» + задача «Предложить пакет» |
| No-show | Note + задача на повторный контакт |
| Купила пакет | Стадия «Первая покупка», клиент «Активный» |
| Потерян | Стадия «Потерян» + причина |

## Ответ на сообщение (секретарь)

Ответьте **reply** на карточку заявки:

- «Написала, никто не ответил…» → `no_answer`
- «Пообщались…» / «Ответила в Telegram…» / «Думает…» → `contacted` (+ Task при «думает»)
- «Предложила intro…» / «Согласилась на intro…» → `intro_offered`
- «Записала на intro …» → `intro_booked`
- «Потерян: цена» → `lost`
- любой другой текст → только Note

Не пишите в заметках диагнозы и лишние ПДн.
